# Egress allowlist for agent sandboxes. One host per line; a leading dot matches
# subdomains. Everything not listed is refused by the proxy, and a sandbox has no
# route around it - the isolated network has no gateway at all.
#
# Keep this short. Every entry is a place a prompt-injected agent could send the
# contents of your repository, and "it needed it once" is how allowlists stop
# meaning anything.
#
# Reload after editing:  dx exec egress kill -HUP 1
